# ADR 0006: Cloudflare Durable Objects 및 KV 기반 분산 세션 아키텍처

## 상태
승인됨 (2026-09-26)

## 맥락
- 서버리스 엣지 환경에서 인스턴스(isolate) 분산으로 인해 인메모리 세션이 분절되어 404 오류가 발생할 수 있음.
- 학습 세션은 문항별 풀이, 채점, 힌트 사용 등 순차적 상태 변화가 발생하므로 강력한 일관성(Strong Consistency)과 영속성이 요구됨.

## 결정 사항
1. **Durable Objects (DO) 단일 진실 공급원**
   - 각 학습 세션(`sessionId`)은 고유한 `StudySessionDO` 인스턴스에 매핑되어 세션 상태(진행도, attempts, 점수)를 전담 관리하고 SQLite 스토리지에 영속화함.
2. **KV 전역 메타데이터 캐시**
   - 세션 생성 시 기본 메타데이터를 `KAGEMORI_KV`에 기록하여 엣지 전역에서 초저지연 상태 확인 및 캐싱을 지원함.
3. **Graceful Fallback & 포트 어댑터**
   - 바인딩 부재 시(단위 테스트 등) In-Memory 어댑터로 자동 폴백하여 개발 및 테스트 독립성을 보장함.

## 결과 및 영향
- 어떤 엣지 위치에서 요청하더라도 동일 세션 DO로 정확히 라우팅되어 상태 유실 및 404 문제가 원천 차단됨.

## 다음 문제 조회 복구 (2026-09-26)

- `/next`는 한 번 조회한 세션으로 문제와 진행 정보를 계산하여 DO/KV 중복 조회를 피한다.
- 클라이언트의 읽기 전용 `/next`는 시도당 10초, 전체 22초 제한 안에서 시간 초과·일시적 서버 오류를 1회 재시도한다. 제출 POST에는 이 정책을 적용하지 않는다.
- 조회 성공 전에는 이전 선택·힌트·해설을 보존한다. 최종 실패 시 같은 세션에서 다시 불러올 수 있으며, 첫 문제 조회 실패도 재시작 없이 복구한다.
- 조회 중 중복 요청을 막고, 세션 초기화 후 도착한 응답은 화면에 반영하지 않는다.
