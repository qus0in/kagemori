# ADR 0002: 2026 투자자산운용사 교재 목차와 출제기준의 D1 관리 계획

- 상태: 계획 승인 대기
- 작성일: 2026-09-25
- 선행 결정: [ADR 0001](0001-investment-manager-dday.md)

## 배경

금융투자교육원의 2026년 투자자산운용사 표준교재 1~5권의 목차를 학습 단위로 정리하고, 시험의 과목별 출제기준과 연결할 필요가 있다. ADR 0001의 현재 앱은 일정 값을 코드에 고정하고 DB를 사용하지 않는다.

## 결정

- 이번 작업의 범위는 공개 목차·출제기준 조사와 Cloudflare D1 기반 관계형 데이터 모델 **계획**이다. D1 생성, 바인딩, 마이그레이션, 시드, API, UI 구현은 포함하지 않는다.
- 교재의 `권 → PART → Chapter → SECTION` 계층과 `시험 과목 → 세부과목` 계층을 분리한다. 둘 사이의 대응은 근거가 있는 다대다 매핑으로 표현한다. 교재 순서와 시험 비중을 같은 값으로 취급하지 않는다.
- 공식 시험 안내에서 확인되는 과목·세부과목별 문항 수는 `출제기준`으로 관리한다. 장·섹션별 실제 출제빈도는 회차별 문제 자료와 분류 근거를 확보하기 전까지 미확인으로 둔다. 추정치와 수험업체 분석은 공식 기준과 별도 출처·방법·확신도와 함께 기록한다.
- 학습 우선순위는 세부과목 문항 배분, 과락선, 공개된 교육업체의 정성적 학습 조언을 바탕으로 한 **잠정 판단**으로 표시한다. 교재 SECTION에 연결한 우선순위를 실제 출제빈도나 공식 중요도처럼 표현하지 않는다. 근거와 재검토 조건을 함께 기록한다.
- 교재 연도·판본, ISBN, 출처 URL, 확인일을 보존한다. 판본이 바뀌어도 과거 목차와 매핑을 덮어쓰지 않는다.
- 구현 단계로 전환하기 직전에 사용자에게 범위와 데이터 출처를 **한 번 다시 확인**한다. 명시적 구현 지시와 그 재확인을 받은 뒤에만 D1 및 앱 변경을 시작한다.

## 결과와 확인 기준

- [목차·D1 계획](../plans/2026-investment-manager-catalog-d1.md)에 5권의 장별 SECTION 번호 범위, 출처, 시험 비중, 잠정 학습 우선순위, 관계형 모델, 검증 순서를 기록한다.
- ADR 0001의 일정 기능과 데이터 저장 정책은 이번 계획 단계에서 유지한다. 향후 구현이 승인되면 두 ADR의 적용 범위를 먼저 확인하고 필요한 변경을 기록한다.
