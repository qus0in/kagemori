# ADR 0007: 누적 풀이 기반 학습 질답 챗봇

- 상태: 채택·구현 (2026-09-27)
- 작성일: 2026-09-27 (Asia/Seoul)
- 선행 결정: ADR 0003(근거·모델), 0005(학습 UX), 0006(저장소)

## 배경

지금까지 푼 문제와 오답을 바탕으로 후속 질문을 주고받는 보조 학습 창이 필요하다. 기존 학습 지도는 문항별 최신 결과만 제공하므로 반복 오답의 변화나 개념 비교를 설명하기에 부족하다.

## 제안

1. 전역 플로팅 버튼 `학습 질문`으로 데스크톱 사이드 패널·모바일 전체 화면 대화창을 연다. 기존 두 메뉴를 유지한다.
2. D1 전체 풀이의 정확한 집계와 문항 의미 검색을 결합한다. 개인용 공통 풀이 기록이라는 기존 범위를 유지하며 통계를 모델이나 벡터 검색으로 추정하지 않는다.
3. 기존 문항 색인으로 후보를 찾고 서버에서 풀이 이력·문항 버전을 대조한 뒤 관련 개념을 가져온다. 새 개념 색인은 초기 범위에 포함하지 않는다.
4. 기록 사실·학습 근거·AI 설명을 구분한다. 과거 오답과 현재 복습 필요를 별도 필터로 제공하고, 답변의 근거 문항과 풀이 날짜를 표시한다.
5. DO에서 확정된 현재 세션 답안을 D1 기록에 중복 없이 합쳐 반영 지연을 보완한다. 공개 가능한 기록만 검색·집계·모델 입력에 사용한다.
6. 미제출 문항의 정답 우회 노출을 막고 모든 풀이 세션 진행 중에는 질답을 잠근다. 서버의 공개 정책을 통과해야 근거 본문·대화 응답을 제공한다.
7. 기존 텍스트 작성·검토·승격 모델 정책을 재사용한다. 검토 전 초안을 스트리밍하지 않고 완료된 답변을 제공한다.
8. 첫 버전 대화는 탭 메모리에 유지한다. 서버 대화 보관·기기 간 대화 동기화·외부 자료 수집은 후속 범위다.

## 영향

- 구현 시 이력 조회 포트, 공개 정책, RAG 유스케이스, 채팅 API와 UI를 추가한다. 채점·출제 흐름은 기존 책임을 유지한다.
- 구체적인 API·실패 처리·출시 조건은 [상세 설계](../plans/study-history-chat-design.md)를 따른다.
- 기능 변경으로 `package.json`을 0.17.0으로 올렸다.

## 구현 기록

- D1에 전체 풀이 질의와 세션 진행 상태를 추가했다. 활성 세션이 있으면 채팅을 잠가 미제출 문제와 시험 점검 답을 질답 경로에서 드러내지 않는다.
- `/api/study/chat`은 D1 기록을 집계하고 Vectorize 후보를 풀이 이력과 대조한다. 관련 결과가 부족하거나 검색 불가하면 풀이 기록 기반으로 제한해 답한다.
- 전역 플로팅 패널은 대화를 탭 메모리에 보관하고 근거 문항·풀이 시각을 보여준다.
- 검증: `git diff --check`, 라인 제한 검사는 통과했다. 타입 검사·빌드는 의존성 설치가 네트워크 오류로 중단되어 실행하지 못했다.
