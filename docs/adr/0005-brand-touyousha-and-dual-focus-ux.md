# ADR 0005: '투자용사' 브랜드 일원화 및 D-day·문제풀기 2대 핵심 UX 집중

## 상태
승인됨 (2026-09-26)

## 맥락
- 기존 서비스명과 메뉴 구조는 분산되어 있었고, RAG·인공지능 등 기술 용어가 전면에 배치되어 수험생 입장에서의 직관성과 사용성이 저하됨.
- 수험생의 실제 핵심 행동은 '시험 D-day 일정 파악'과 '합격을 위한 문제 풀이 및 개념 확인' 2가지에 집중됨.

## 결정 사항
1. **브랜드 및 프로젝트명 일원화 ('투자용사')**
   - 프로젝트명을 '투자용사'로 확정하고, 전용 파비콘(방패·상승 심볼 SVG)과 문서 타이틀을 정비함.
2. **2대 핵심 영역으로 UX 압축**
   - 상단 내비게이션을 `D-day`와 `문제 풀기` 2개로 간소화하여 사용자 동선을 단순화함.
   - 복잡한 하위 메뉴는 핵심 화면의 보조 컨텍스트로 정돈함.
3. **담백한 학습자 중심 표현 전환 (AI 수식어 지양)**
   - 'RAG 적응형 학습' ➔ '시험 문제 풀기'
   - 'AI 힌트 요청' ➔ '핵심 힌트 보기'
   - 기술적 과시 표현을 배제하고, 수험서와 표준교재 기반의 담백한 어조를 유지함.

## 결과 및 영향
- 수험생에게 군더더기 없는 직관적인 사용 경험을 제공함.

## 누적 학습 영역 시각화 (2026-09-26)

- `/study`의 세 모드 선택 바로 아래에 과목별 세부과목 영역 지도를 배치하고, 풀이 중·완료 후에도 표시한다.
- 목표는 각 세부과목에서 힌트 없는 정답을 1개 이상 확인하는 것이다. 채움 진도는 `해당 조건을 충족한 세부과목 수 / 전체 세부과목 수 × 100`이며, 시험 비중·숙달률·합격 확률과 구분한다. 전체 및 남은 %와 영역 수를 표시한다.
- 세부과목은 기존 출제기준 API에서 가져온다. 미풀이·복습 필요(오답/힌트 후 정답)·정답 확인을 색과 문자로 구분하며, 각 영역을 선택하면 결과를 볼 수 있다.
- 채점 성공 결과의 문항별 최신 상태만 브라우저 localStorage에 저장한다. 세션 초기화와 분리하고 새로고침 후 복원한다. 이전 서버 세션 소급 조회와 기기 간 동기화는 제공하지 않는다. 서버의 채점·세션 데이터는 원본으로 유지한다.
- 저장 실패 시 현재 화면에서 계속 집계하고 저장 불가 상태를 안내한다. 전체 기록 삭제 기능을 제공한다. 기존 기록이 없을 때는 0%로 시작한다.
- 중복 제출·실패는 진도를 늘리지 않으며 힌트 사용 결과를 독립 정답으로 계산하지 않는다. 단일 정답은 범위 확인 지표이며 숙달 판정이 아니다.

## 학습 마크다운 표시 보완 (2026-09-26)

- 힌트·해설의 공통 `MarkdownView`에 `remark-cjk-friendly`를 적용한다. `**'원화로 표시된 양도성 예금증서(CD)'**는`처럼 문장 부호와 한국어 조사가 맞닿아도 강조를 인식한다.
- 문자열에 공백·제로폭 문자·HTML을 삽입하지 않고 파서 단계에서 처리한다. 코드, 이스케이프, 링크와 기존 HTML 안전 처리 동작을 보존한다.
- 줄바꿈 정규화 결과를 렌더러에 전달하고, 실제 React HTML 출력으로 강조 및 기존 문법의 회귀를 검증한다.
- 참고: [remark-cjk-friendly](https://github.com/tats-u/markdown-cjk-friendly/tree/main/packages/remark-cjk-friendly)
